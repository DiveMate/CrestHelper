# 总纲：用自研软件取代原厂 App

**一句话目标**：扫描 → 连接 → 下载 → **高阶可视化分析**，四个环节全部自有，
并且在「分析」这一环做到原厂 App 做不到的事。

> 原厂 App 的短板就是我们的机会：它只做搬运和列表，不做**风险复盘**。
> 真正的价值在「换算法重算、发现隐藏风险、合并/过滤脏日志」。

## 1. 分阶段路线（按「不装工具链也能推进」排序）

### M1 · 数据管道收尾（0 依赖，现在就能做完）
- [x] 292 条全部下载
- [ ] `tools/batch_parse.py`：批量解析 → `dives.csv` + `samples.csv`
- [ ] 基础画像：时间跨度、深度分布、水温、时长、每月潜次

### M2 · 分析引擎（0 依赖，Python 先跑通算法）
把文档 `03-日志分析与算法设计.md` 的设计落成可执行代码：
- [ ] **减压算法**：ZHL-16C + Gradient Factor（GF 低/高可切换）
- [ ] **隐藏风险指标**：GF99、ceiling 越界累计秒数、上升速率超限
- [ ] **日志合并**：SI < 阈值的「升水又下水」判定为同一次潜水，并把水面段当作真实水面间隔积分排气
- [ ] **无效日志过滤**：浅于 2m / 短于 60s / 指纹去重等（默认只标记不删）
- [ ] **多算法对拍**：GF 30/85 vs 50/70 vs 80/80，看风险结论怎么变

> 先在 Python 里跑通并验证数值，再往 Rust 里搬 —— **算法必须先有可信的参考实现**，
> 否则 Rust 版本无从对拍。

### M3 · 可视化（0 依赖，HTML + ECharts 单文件）
- [ ] 剖面图（深度-时间曲线 + 温度叠加 + 报警事件标记）
- [ ] 风险热力图（GF99 随时间的曲线 + 越界区间高亮）
- [ ] 统计报表（月度潜次、深度分布、水面间隔分布）
- [ ] 多算法对比视图（同一次潜水，不同 GF 下的减压义务差异）

> 做成单文件 HTML，双击就能看 —— 这一步能最早看到「取代原厂 App」的样子。

### M4 · 安卓原生核心（算法 + 解析 + BLE，Kotlin/NDK）
> 用户已拍板「只在安卓开发」，故不引入 Rust/Flutter，桌面端暂缓。
> 所有计算逻辑先用 Python（`deco.py`）和 JS（`deco.js`）验证，**逐位对拍**后再移植，避免无基准。

- **减压算法 `deco`**：把 `deco.py` 移植成 Kotlin（ZHL-16C + GF，可切 5 档算法）。`deco.js` 已是第三份基准。
- **BLE 传输**：用 Android `BluetoothLeScanner` 复刻 `cr4_probe.py` 的握手——已实测的 GATT 参数直接复用：
  - 数据 service `f000ffe0-ab12-45ec-84c8-46483f4626e9`
  - 数据 characteristic `f000ffe1-ab12-45ec-84c8-46483f4626e9`（收发同一条，notify+write）
  - **必须 `address_type=random`**（CR-4 是随机私有地址，否则 Unreachable）
  - 包格式 `[grp][cmd][dir][len][payload][csum]`，csum=`(sum^0xFF)`，响应 group=请求 group+1
- **数据解析**：优先用 **NDK 编译 libdivecomputer 的 C 解析器**（`deepsix_excursion_parser.c`，已验证），经 JNI 调；
  备选是 Kotlin 重写 excursion 协议（风险高，仅在 NDK 走不通时考虑）。
- **存储**：Room（SQLite）+ 指纹增量，原始 blob 永不删，可全库重跑。

### M5 · 安卓原生 App（Kotlin + Jetpack Compose，需 Android SDK + JDK17）
- UI 平移 `web/` 原型已验证的 5 页结构（日志 / 详情 / 分析 / 统计 / 设备）
- 算法切换实时重算、GF99 风险曲线、多算法对拍等交互直接复用 M4
- 不依赖 Flutter，不覆盖桌面端

## 2. 工具链现状与决策点

> 路线收敛为「纯安卓原生」后，Rust / Flutter / VS Build Tools 都不再需要。

| 组件 | 本机状态 | 用途 | 说明 |
|---|---|---|---|
| Python + bleak | ✅ 已装 | 算法验证 / 下载脚本 | 减压内核参考实现 |
| MinGW gcc | ✅ 有 | 解析器验证 | `build/parse_cr4.exe` |
| **Android SDK** | 🚧 **安装中** | M4/M5 | 落地 `$ANDROID_HOME`，`ANDROID_HOME` 指向它 |
| **JDK 17（Temurin）** | 🚧 **安装中** | M4/M5 | AGP 8 + 编译 API34/35 **必须 JDK17**；JDK 11 不够 |
| JDK 11 | ✅ 有 | 仅 sdkmanager 旧版兼容 | 不用于编译 App |
| Android NDK | ⚠️ 待装 | M4 编 libdivecomputer | SDK 装完用 `sdkmanager ndk;27.0.12077973` 补 |
| Gradle / Android Studio | ⬜ 可选 | 构建 / IDE | 可仅用 Gradle 命令行；Android Studio 按需另装 |

**关键路径（SDK 装完后）**：NDK 补装 → 用 NDK 编 libdivecomputer 出 `libdc.so` → Kotlin 经 JNI 调 → Compose UI 平移 web 原型。

**SDK 落地信息（装完填入）**：
- `ANDROID_HOME = $ANDROID_HOME`
- `JAVA_HOME = $JAVA_HOME`
- compileSdk = 35（Android 15），minSdk = 26（Android 8.0，BLE 通用）

## 3. 我们要做得比原厂好的地方（差异化清单）

1. **换算法重算** —— 表用 GF 30/85 判免减压，我用 GF 50/70 重算看看是不是其实有减压义务。
2. **隐藏风险量化** —— GF99 峰值、ceiling 越界累计秒数、上升速率超限次数，全部量化成数字。
3. **脏日志治理** —— 中途升水又下水自动合并；浅/短/重复记录自动标记。
4. **数据主权** —— 原始 blob 永不删，改阈值可全库重跑，所有判定可撤销。
5. **跨平台一致性** —— 桌面和安卓共用同一内核，不会出现「手机上看和电脑上看不一样」。
